{# The whole layout. Every page extends this one. #} {# Two rules hold this site's link checking together, and they are both here. 1. Every internal link in a TEMPLATE goes through `get_url(path="@/...md")`. That form resolves against the content library, so a link to a page that does not exist fails `zola build` outright. A hand-written `href="/x/"` does not — `zola check` does not read template hrefs at all, and neither does the build. If you write a raw internal href here, nothing will ever tell you when it rots. 2. Every internal link in CONTENT is written `@/page.md`, which `zola check` does validate. Root-relative and `../` links are silently unchecked. Between them the build itself is the link check, which is why this site pins no separate crawler. #} {# The viewport meta is load-bearing for the phone criterion: without it mobile Safari renders at a 980px viewport and scales the page down, so every media query below is measured against the wrong width. #} {% block title %}{{ config.title }}{% endblock title %} Skip to content
